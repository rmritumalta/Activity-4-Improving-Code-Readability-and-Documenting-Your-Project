# Hypothenus Calculator
## Description:
Calculate the hypotenuse of a right triangle using the a and b values the user provided.
## How to Run:
find and click on Hypotenuse.py in the GitHub repository, then run.
## Input Needed
required inputs are a and b.
## Sample Output:
Sample input values: a = 2, b = 3;
Result:
Enter the value of a: 2
Enter the value of b: 3
The hypotenuse of the triangle using both sides a and b is 3.61
